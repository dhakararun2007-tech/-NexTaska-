# NexTaska

A browser-based task and notes organizer. Your tasks and notes are saved in this browser with localStorage.

## Run the project

1. Extract the ZIP file.
2. Open the extracted `NexTask  git` folder.
3. Open `index.html` in a modern browser.
4. Use **Dashboard**, **My Tasks**, and **Notes & Ideas** from the navigation.

Tasks and notes stay in the same browser profile on this device. Clearing browser site data will remove them.

## Features

- Create tasks with a title, description, due date, priority, category, and optional reminder.
- Mark tasks complete or pending, delete them, and filter the list.
- See task counts and progress on the dashboard.
- Create, search, filter, and delete notes.

All pages share the `nextaska.workspace.v1` localStorage key in `script.js`.
